# Awodumila, Tobi Ebenezer

### Senior Software Engineer • Backend Systems & Applied AI

I design and build reliable backend architectures, production web applications, and practical AI systems. My day-to-day work focuses on clean code, solid database schemas, resilient APIs, and taking machine learning models out of notebooks into production environments.

---

### What I Do

- **Backend Architecture & APIs**: Designing clean, scalable services and REST/GraphQL APIs with PHP (Laravel), Python (Flask, FastAPI), Go, and Node.js. Focused on maintainability, database efficiency (PostgreSQL, MySQL), and rock-solid auth flows.
- **Applied AI & Machine Learning**: Building production-ready AI services — from spatial-temporal Computer Vision pipelines (YOLO, OpenCV) and satellite time-series transformers (PatchTST, TFT) to local Retrieval-Augmented Generation (RAG) engines and vector search (Qdrant, Chroma).
- **Full-Stack Engineering**: Building fast, reactive frontends and dashboard interfaces using TypeScript, Next.js (App Router), React, and Tailwind CSS.
- **Developer Tooling & Packaging**: Authoring open-source packages (such as `tobiebenezer/php-ai` on Packagist), containerizing environments with Docker, and setting up automated CI/CD workflows.
